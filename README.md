# mouse-trail

`run-mouse-trail.bat`을 실행하면 시스템 트레이에서 동작합니다. 아이콘 우클릭 → Exit로 종료합니다.

## 2026-10-11

- 터미널 상시 표시를 없애고 트레이 아이콘과 종료 메뉴를 추가했습니다.
- 곡선을 짧은 선분으로 계산해 DrawPath 오류 발생 경로를 제거했습니다.
- 그리기 버퍼를 재사용하고 큰 영역의 할당을 제한했습니다. 매우 큰 화면 이동에서는 잔상이 초기화될 수 있습니다.

# 2026-09-27

- 마우스 트레일의 좌표 사이에 중간 샘플을 추가해 점 밀도를 2배로 높였습니다.
- 선분 끝의 투명도 중첩으로 보이던 밝은 점을 제거했습니다.
- 직선 조각처럼 보이던 경로를 진동과 과보간을 억제한 부드러운 곡선으로 개선했습니다.
- 트레일의 길이, 두께, 지속 시간은 기존과 동일하게 유지했습니다.
